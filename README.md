# Krishna Nand Tiwari - Portfolio

Personal portfolio and technical showcase built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

**Live Site:** [krishnaworks-10.vercel.app](https://krishnaworks-10.vercel.app)

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations & Interactions:** [Framer Motion](https://www.framer.com/motion/) & Three.js
- **Icons:** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Themes:** Light / Dark mode via [next-themes](https://github.com/pacocoursey/next-themes)
- **Palette Navigation:** Command Menu (⌘K / Ctrl+K) via [cmdk](https://cmdk.paco.me/)

## Features

- **Project Deep-Dives:** Detailed overviews, live demo links, and architectural reviews for SonicDrop, Argus Search, p2pcopy, RepurposeAI, Kinship, and Smart Learn.
- **Engineering Notes & Blogs:** In-depth technical articles covering WebAssembly, DSP audio transmission, AST query optimization, WebRTC data channels, and generative AI pipelines.
- **Live Bengaluru Time & Blueprint Grids:** Precision-engineered micro-dot grid alignment and interactive canvas particles.
- **Command Palette:** Keyboard-driven navigation across sections, profiles, and actions (`Ctrl+K` / `⌘K`).

## Development

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Type check
npm run typecheck

# Build for production
npm run build
```
